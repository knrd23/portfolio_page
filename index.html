3Selected work

3.1Real-time anomaly detection pipeline

PyTorch · Apache Kafka · Docker · Prometheus · Grafana

An end-to-end MLOps pipeline that processes live IoT and financial data streams. An unsupervised PyTorch autoencoder scores each incoming record by its reconstruction loss1 1The autoencoder learns to reconstruct typical inputs. Records it reconstructs poorly are unlike what it has seen, and get flagged as anomalies. No labels needed. and the results are exposed to Prometheus and visualised live in Grafana.

3.2Credit card fraud detection

Python · MLP · Jupyter

Detecting fraudulent transactions in a highly imbalanced dataset. A tuned multi-layer perceptron reached an F1-score of 0.8242. 2F1 rather than accuracy: when fraud is a tiny fraction of transactions, a model that never flags anything still scores near-perfect accuracy.

Notebook on GitHub ↗

3.3PLS vs logistic regression on DNA data

R · Partial Least Squares · Bootstrap

A comparative statistical analysis of DNA data using Partial Least Squares3 and logistic regression, with model performance assessed using bootstrap validation techniques. 3PLS projects the predictors onto a few latent components, which helps when there are far more variables than observations, as is typical for genetic data.
